# 文档标注项目技术文档

## 1. 架构设计

### 1.1 设计原则

| 原则 | 说明 | 实现方式 |
|-----|------|---------|
| **简洁优先** | 避免过度设计，保持项目结构简单清晰 | 3层目录结构，少量核心类 |
| **解耦设计** | 各模块职责单一，依赖关系清晰 | 接口抽象 + 工厂模式 |
| **可扩展** | 新增功能不修改现有代码 | 插件注册机制 |
| **可替换** | OCR/LLM模型可灵活替换 | 模型接口抽象 |

## 2. 核心设计

### 2.1 处理器基类设计

**设计思路**: 使用简单的抽象基类，所有处理器继承并实现 `process()` 方法。

```python
# core/base.py
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Any, Dict, Optional

@dataclass
class ProcessResult:
    """处理结果（统一的返回格式）"""
    success: bool
    data: Any = None
    errors: list = field(default_factory=list)
    metadata: Dict[str, Any] = field(default_factory=dict)

    def __post_init__(self):
        if self.errors is None:
            self.errors = []

    def add_error(self, error: str) -> None:
        """添加错误消息。"""
        self.errors.append(error)
        self.success = False

    def to_dict(self) -> Dict[str, Any]:
        """转换为字典。"""
        return {
            "success": self.success,
            "data": self.data,
            "errors": self.errors,
            "metadata": self.metadata,
        }

class BaseProcessor(ABC):
    """处理器基类"""

    def __init__(self, config: Optional[Dict] = None):
        self.config = config or {}

    @abstractmethod
    def process(self, input_data: Any) -> ProcessResult:
        """处理输入数据，返回结果"""
        pass
```

**设计说明**:
- 仅3个核心概念：`BaseProcessor`（基类）、`process()`（处理方法）、`ProcessResult`（结果）
- 不使用注册表、不使用元类，保持简单
- 新增处理器只需继承并实现 `process()` 方法

### 2.2 Schema设计

**设计思路**: 使用 dataclass 定义结构化的数据模型，支持嵌套和可选字段。

```python
# core/schema.py
from dataclasses import dataclass, field
from typing import Optional, Literal
from enum import Enum

class FileType(str, Enum):
    PDF = "pdf"
    DOC = "doc"
    EXCEL = "excel"
    PPT = "ppt"
    HTML = "html"
    TXT = "txt"
    MD = "md"

# 文件扩展名到 FileType 的映射
EXT_TO_FILE_TYPE: Dict[str, FileType] = {
    ".pdf": FileType.PDF,
    ".doc": FileType.DOC,
    ".docx": FileType.DOC,
    ".xls": FileType.EXCEL,
    ".xlsx": FileType.EXCEL,
    ".ppt": FileType.PPT,
    ".pptx": FileType.PPT,
    ".html": FileType.HTML,
    ".htm": FileType.HTML,
    ".txt": FileType.TXT,
    ".md": FileType.MD,
}

class LayoutType(str, Enum):
    SINGLE = "single"
    DOUBLE = "double"
    MIXED = "mixed"

@dataclass
class TableProfile:
    """表格特征"""
    long_table: bool = False
    cross_page_table: bool = False
    table_dominant: Optional[bool] = None  # 可选

@dataclass
class ChartProfile:
    """图表特征"""
    cross_page_chart: bool = False

@dataclass
class DocProfile:
    """文档通用标注（适用于所有文档类型）"""
    layout: LayoutType = LayoutType.SINGLE  # 非PDF默认single
    has_image: bool = False
    has_table: bool = False
    has_image_table: bool = False      # 图片形式的表格（扫描版/截图）
    has_complex_table: bool = False    # 复杂表格（多列/多行）
    has_formula: bool = False
    has_chart: bool = False
    image_text_mixed: bool = False     # 是否为图文混排
    reading_order_sensitive: Optional[bool] = None  # 仅PDF

    # 仅PDF，当 has_table=True 时填充
    table_profile: Optional[TableProfile] = None

    # 仅PDF，当 has_chart=True 时填充
    chart_profile: Optional[ChartProfile] = None

@dataclass
class DocumentAnnotation:
    """文档标注结果"""
    doc_id: str
    file_type: FileType

    # 所有文档类型都有
    doc_profile: Optional[DocProfile] = None

    def to_dict(self) -> Dict:
        """转换为字典（用于JSON输出）"""
        # 实现略
```

**设计说明**:
- 使用 dataclass 自动生成 `__init__`、`__repr__` 等方法
- 使用 `Optional` 表示可选字段
- 使用 `Literal` 或 `Enum` 限制取值范围
- `doc_profile` 适用于所有文档类型，`table_profile`/`chart_profile` 仅 PDF 输出
- 天然支持 `.to_dict()` 转换为 JSON

### 2.3 Pipeline设计

**设计思路**: 简单的顺序执行器，不引入复杂的概念。

```python
# core/pipeline.py
from typing import List, Any
from core.base import BaseProcessor, ProcessResult

class Pipeline:
    """处理管道 - 顺序执行多个处理器"""

    def __init__(self, steps: List[BaseProcessor] = None):
        self.steps = steps or []

    def add(self, processor: BaseProcessor) -> "Pipeline":
        """添加处理器"""
        self.steps.append(processor)
        return self  # 支持链式调用

    def execute(self, input_data: Any) -> ProcessResult:
        """执行管道"""
        current_data = input_data
        all_errors = []

        for processor in self.steps:
            result = processor.process(current_data)

            if not result.success:
                # 可选：根据配置决定是否继续
                return ProcessResult(success=False, errors=result.errors)

            current_data = result.data

        return ProcessResult(success=True, data=current_data)
```

**设计说明**:
- 不引入条件执行、并行执行等复杂特性
- 错误时直接返回（可扩展为 continue_on_error）
- 保持简单直观

## 3. 处理器设计

### 3.1 处理器分类

| 处理器 | 职责 | 输入 | 输出 |
|-------|------|------|------|
| `DocParser` | 解析文档，提取原始内容和结构化元素信息（Legacy） | 文件路径 | DocContent（含 metadata） |
| `DoclingParser` | 使用 Docling 进行高精度文档解析，支持表格/图片精确检测 | 文件路径 | DocContent（含精确元素信息） |
| `ElementDetector` | 检测图片/表格/公式/图表 | DocContent | ElementList |
| `FeatureExtractor` | 提取跨页/长表格等特征（仅PDF） | ElementList + DocContent | FeatureSet |
| `LayoutClassifier` | 分类布局类型，生成最终标注 | DocContent + FeatureSet | DocumentAnnotation |

**各文件类型检测方式**:

| 文件类型 | 检测方式 | 说明 |
|---------|---------|------|
| PDF | OCR 检测页面图像 | 通过 OCR 模型检测 images/tables/formulas/charts |
| docx | python-docx 结构化解析 | `doc.tables`、`doc.inline_shapes`、OMML 检测 |
| pptx | python-pptx 结构化解析 | `shape.has_table`、`shape.shape_type`、`shape.has_chart` |
| xlsx | openpyxl 结构化解析 | `has_table=True`、`worksheet._images`、`worksheet._charts` |
| html | DOM 解析 | `<table>`、`<img>` 标签检测 |
| txt/md | 无元素检测 | 所有 has_* 字段为 False |

## 5. 服务入口设计

### 5.1 统一服务类

```python
# service.py
from pathlib import Path
from typing import Optional, Dict
from core.pipeline import Pipeline
from core.schema import DocumentAnnotation, FileType
from processors.doc_parser import DocParser
from processors.element_detector import ElementDetector
from processors.feature_extractor import FeatureExtractor
from processors.layout_classifier import LayoutClassifier
from models.ocr import OCRModel
from models.llm import LLMModel

class AnnotationService:
    """文档标注服务 - 统一入口"""

    def __init__(
        self,
        ocr_model: Optional[OCRModel] = None,
        llm_model: Optional[LLMModel] = None
    ):
        self.ocr_model = ocr_model
        self.llm_model = llm_model

    def annotate(self, file_path: str) -> DocumentAnnotation:
        """
        标注文档

        Args:
            file_path: 文档路径

        Returns:
            DocumentAnnotation: 标注结果
        """
        # 1. 构建 Pipeline
        pipeline = self._build_pipeline()

        # 2. 执行
        result = pipeline.execute(file_path)

        # 3. 返回结果
        return result.data

    def _build_pipeline(self) -> Pipeline:
        """根据文档类型构建 Pipeline"""
        return Pipeline() \
            .add(DocParser()) \
            .add(ElementDetector(config={"ocr_model": self.ocr_model})) \
            .add(FeatureExtractor(config={"llm_model": self.llm_model})) \
            .add(LayoutClassifier(config={"llm_model": self.llm_model}))

# 使用示例
service = AnnotationService(
    ocr_model=PaddleOCRModel(),
    llm_model=OpenAILLM(api_key="...")
)

annotation = service.annotate("document.pdf")
print(annotation.to_dict())
```

## 7. 扩展性设计

### 7.1 新增文档类型

1. 在 `FileType` 枚举中添加新类型
2. 在 `DocParser` 中添加对应的解析逻辑
3. 定义新的 Profile（如 `ExcelProfile`）

### 7.2 新增标注字段

1. 在对应的 `Profile` dataclass 中添加字段
2. 在相关处理器中添加提取逻辑
3. 无需修改框架代码

### 7.3 新增处理器

1. 继承 `BaseProcessor`
2. 实现 `process()` 方法
3. 在 Pipeline 中添加即可

### 7.4 切换模型

```python
# 只需修改初始化时的 model 实例
service = AnnotationService(
    ocr_model=TesseractOCRModel(),  # 切换到 Tesseract
    llm_model=ClaudeLLM()           # 切换到 Claude
)
```

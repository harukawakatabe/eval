# 文档标注项目需求文档

## 1. 项目概述

### 1.1 项目背景
构建一个通用的文档标注系统，支持对多种格式文档（PDF、Word、Excel、PPT、HTML、TXT）进行结构化标注，提取文档特征信息。

### 1.2 核心目标
- 支持多种文档格式的解析和标注
- 模块化设计，每个标注功能独立可扩展
- 支持外接OCR模型进行文本识别
- 支持外接LLM进行智能判断
- 输出结构化的标注数据

## 2. 功能需求

### 2.1 文档解析能力
| 文档类型 | 标识 | 说明 |
|---------|------|------|
| PDF | `pdf` | 便携式文档格式 |
| Word | `doc` | Microsoft Word 文档 |
| Excel | `excel` | 电子表格文档 |
| PPT | `ppt` | 演示文稿文档 |
| HTML | `html` | 网页文档 |
| TXT | `txt` | 纯文本文档 |

### 2.2 文档通用标注能力

适用于所有支持的文档类型（PDF、Word、Excel、PPT、HTML、TXT）。

#### 2.2.1 元素检测
| 元素类型 | 字段 | 说明 | 检测方式 |
|---------|------|------|----------|
| 图片 | `has_image` | 文档中是否包含图片 | PDF: pdfplumber检测；docx/pptx: 结构化解析；xlsx: 嵌入图检测 |
| 表格 | `has_table` | 文档中是否包含表格 | PDF: pdfplumber检测；docx/pptx: 结构化解析；xlsx: 恒为true |
| 公式 | `has_formula` | 文档中是否包含数学公式 | docx: OMML检测；xlsx: 公式单元格检测 |
| 图表 | `has_chart` | 文档中是否包含统计图表 | PDF: 矩形/线条检测；pptx: shape检测；xlsx: 图表对象检测 |
| 图文混排 | `image_text_mixed` | 文档是否同时包含图片和大量文字 | 所有类型：has_image && 文字>100字符 |

#### 2.2.2 布局检测（仅 PDF）
- **单页布局** (`single`): 每页内容独立，无连续排版
- **双页布局** (`double`): 跨页连续排版（如展开表格）
- **混合布局** (`mixed`): 既有单页也有双页内容

> 非 PDF 文档默认 `layout: single`

#### 2.2.3 可选标注
- **阅读顺序敏感** (`reading_order_sensitive`): 标注内容的阅读顺序是否重要（仅 PDF）

### 2.3 表格特征标注（仅 PDF）

| 特征 | 字段 | 说明 |
|-----|------|------|
| 表格主导 | `table_dominant` | 文档是否以表格内容为主 |
| 长表格 | `long_table` | 是否包含跨多页的长表格 |
| 跨页表格 | `cross_page_table` | 表格是否跨页显示 |

> 非 PDF 文档不输出 `table_profile`

### 2.4 图表特征标注（仅 PDF）

| 特征 | 字段 | 说明 |
|-----|------|------|
| 跨页图表 | `cross_page_chart` | 图表是否跨页显示 |

> 非 PDF 文档不输出 `chart_profile`

## 3. 数据结构设计

### 3.1 文档基础信息
```yaml
document:
  doc_id: string              # 文档唯一标识
  file_type: enum             # 文件类型: doc|pdf|excel|ppt|html|txt
  file_path: string           # 文件路径
  file_size: int              # 文件大小（字节）
  page_count: int             # 页数
```

### 3.2 文档通用标注
```yaml
doc_profile:                  # 所有文档类型都有
  layout: enum                # single|double|mixed（非PDF默认single）
  has_image: bool
  has_table: bool
  has_formula: bool
  has_chart: bool
  image_text_mixed: bool      # 图文混排（同时包含图片和大量文字）
  reading_order_sensitive: bool  # 可选，仅PDF

  table_profile:              # 仅PDF，当 has_table=true 时
    table_dominant: bool      # 可选
    long_table: bool
    cross_page_table: bool

  chart_profile:              # 仅PDF，当 has_chart=true 时
    cross_page_chart: bool
```

## 4. 非功能性需求

### 4.1 扩展性
- 新增文档类型支持无需修改现有代码
- 新增标注字段通过配置即可实现
- 支持多种OCR模型接入
- 支持多种LLM模型接入

### 4.2 解耦性
- 文档解析、标注处理、模型调用三者解耦
- 每个标注处理器独立运行
- 处理器之间通过标准接口通信

### 4.3 简洁性
- 项目结构不宜过度复杂
- 避免过度抽象和设计模式滥用
- 保持代码直观易懂

## 5. 技术选型原则

- **Python**: 主要开发语言
- **可插拔模型**: OCR和LLM作为外部服务
- **配置驱动**: 标注规则可通过配置定义
- **标准输出**: JSON格式标注结果
